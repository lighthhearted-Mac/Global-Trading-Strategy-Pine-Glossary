1. What a referral code is

A referral code is a short string that Composer issues to each existing account holder. When somebody opens a new account and enters that code, Composer credits both parties: the person who shared the code and the person who used it. It is a standard customer-acquisition mechanism, used across the brokerage industry, and it costs the new account holder nothing.

The code is tied to the account that issued it, not to any particular person or website. It is entered during account creation and generally cannot be applied afterwards, which is the single most common way people miss the credit. See Limitations.

2. What each side receives

A completed referral pays $50 to the new account holder and $100 to the person who shared the code, as displayed on Composer's own invite screen at the time of writing. The amounts are not equal, and this page says which is which rather than rounding them into a vague "you both earn".

Put plainly: the code is free money for opening an account you were going to open anyway. It is not a discount, a trial credit or a deposit match. It is a cash bonus for filling in one field that most people scroll straight past, and the only thing standing between a reader and $50 is remembering to paste eleven characters at the right moment.

These figures and their conditions are set by Composer and can change without notice. Promotions of this kind normally carry requirements, such as funding the account within a certain window or maintaining a minimum balance for a period. Composer defines those terms, this site does not, and no attempt is made here to restate them from memory. Check the offer text shown during your own signup, and treat what it says as authoritative over anything on this page.

3. Redeeming a code when you sign up

The flow is short. The only step that catches people out is the third one, because the field is easy to scroll past.

  1. Copy the code first, before you start. Have it on your clipboard rather than in another tab, since leaving a half-finished signup to go and fetch it is how the field ends up skipped.
  2. Open Composer and begin creating an account. Use the normal signup route at composer.trade.
  3. Find the referral or promo code field and paste the code in. It usually appears during account creation rather than after, and it may be collapsed behind a link such as "Have a referral code?". This is the step that decides whether you get $50 or $0. Paste rather than retype: the codes mix upper and lower case, and a capital I and a lowercase l are indistinguishable in most interface fonts.
  4. Check that the code was accepted before you continue. A valid code normally produces some visible confirmation. If the form simply moves on without acknowledging it, assume it did not register and resolve that before finishing.
  5. Complete signup and funding as Composer instructs. The credit is generally tied to completing the process, not to creating the account alone.

5. Sharing your own code

Once you hold an account, Composer issues you a code of your own, and the larger half of the deal becomes yours: $100 per completed referral. To find it, open Composer and look for the invite or referral screen, which displays your code alongside a copy button.

A few things make the difference between a code that gets used and one that does not:

  • Send the code to people who were already considering the platform. A referral code is a sweetener on a decision somebody has already made. It is a poor reason, on its own, for anyone to open a brokerage account.
  • Lead with what they get, not what you get. "You get $50" is the part that moves; the amounts differ, and leading with your own benefit reads exactly as it is.
  • Tell them it has to be entered during signup. This is the step that fails, and your referral fails with it.
  • Disclose that you benefit. If you are sharing a code publicly rather than with a friend, say plainly that you receive a bonus. In the United States this is not merely good manners: the FTC's endorsement guidance expects a clear disclosure of a material connection, and a referral bonus is one.

6. Limitations and common problems

  • The code must be entered during account creation. Applying one to an existing account is normally not possible, and support cannot always add it later.
  • One code per new account, and codes do not stack with each other.
  • Self-referral does not work. Opening a second account to use your own code is the kind of thing brokerage terms address directly.
  • A mistyped code fails silently. Composer will usually reject an invalid code outright, but a code that is wrong in a way that happens to match nothing simply produces no credit, and signup continues normally. This is why every code on this page is copied from one place and never retyped.
  • Terms change. The amounts in section 2 were accurate when this page was written and are not monitored for changes. Composer's own signup screen is the authority.
